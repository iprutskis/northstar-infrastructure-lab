# Enterprise Windows Infrastructure Project

## What is this project?

This is my first attempt at building and managing a realistic enterprise Windows environment from scratch.

I created this lab to learn the technologies, tools and processes used by IT Support Technicians and Systems Administrators through practical, hands-on experience.

Rather than simply following tutorials, I want to understand why technologies are implemented, how they work together, and how they are deployed, managed and supported in real business environments.

---

## Why am I building this?

The main goal of this project is to develop practical enterprise IT skills by designing, deploying, documenting, maintaining and troubleshooting a Windows-based business environment.

As the project grows, I also plan to treat the lab as a live business environment by working through realistic incident, service request and project-based tickets similar to those encountered in enterprise IT.

## Long-Term Goals

- Gain practical experience with enterprise Windows technologies
- Develop troubleshooting and problem-solving skills
- Learn industry best practices
- Improve technical documentation skills
- Simulate a realistic enterprise IT environment
- Practise supporting a business through realistic ticket-based scenarios
- Build a portfolio project that demonstrates technical growth and continuous learning

## Documentation

The documentation is developed alongside the project and will continue to evolve as the environment grows.

As I gain more experience and expand the lab, the documentation may be updated to better reflect the standards and practices used within professional IT environments.

The goal is to produce clear, consistent and practical documentation that could be used by other technical staff supporting the environment.
